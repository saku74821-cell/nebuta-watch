## 設定步驟（全部用網頁就能完成，手機也可以）

### 1. 手機推播：ntfy
1. 手機安裝 **ntfy** App（App Store / Google Play 都有）。
2. 點「＋」訂閱一個主題，名稱取一個別人猜不到的，例如 `nebuta-aomori-8492`。
3. 記下這個名稱，第 4 步會用到。

### 2. 樂天 API 金鑰（免費）
1. 到 https://webservice.rakuten.co.jp/ 用樂天帳號登入 →「アプリID発行」→ 建立應用程式。
2. 記下 `アプリID`（applicationId）和 `アクセスキー`（accessKey）。

### 3. 把程式放上 GitHub
1. 到 https://github.com 註冊帳號（免費）。
2. 右上角「＋」→ **New repository** → 名稱隨意（例如 `nebuta-watch`）→ 選 **Public** → Create。
   （Public 才有無限的免費執行時數。金鑰會放在下一步的 Secrets 裡，不會公開。）
3. 在新倉庫頁面點 **uploading an existing file**，把 `nebuta_watch.py`、`official.py`、`config.json`、`requirements.txt` 拖進去 → **Commit changes**。
4. 再點 **Add file → Create new file**，檔名輸入 `.github/workflows/watch.yml`（打 `/` 會自動變資料夾），把 `watch.yml` 的內容整段貼上 → **Commit changes**。

### 4. 填入金鑰（Secrets）
倉庫頁面 → **Settings** → 左邊 **Secrets and variables → Actions** → **New repository secret**，依序新增：

| Name | Secret |
|---|---|
| `NTFY_TOPIC` | 第 1 步的主題名稱 |
| `RAKUTEN_APP_ID` | 樂天 アプリID |
| `RAKUTEN_ACCESS_KEY` | 樂天 アクセスキー |

（想同時收 Email，可以再加 `SMTP_USER`（Gmail 地址）和 `SMTP_PASSWORD`（Gmail 應用程式密碼）。）

### 5. 啟動
倉庫頁面 → **Actions** → 左邊點「睡魔祭空房監控」→ **Run workflow**。跑完（約 2–3 分鐘）變綠色勾勾就成功了，之後每 10 分鐘會自動執行。

## 要注意的地方

- **GitHub 排程會延遲**：深夜的實際間隔可能是 10–20 分鐘；白天是程式自己連續跑，不受影響。
- **60 天沒動倉庫，GitHub 會自動暫停排程**，屆時會寄信通知你。回到 Actions 頁面按「Enable workflow」就能恢復。
- 同一筆空房只通知一次；被訂走後如果又釋出，會再通知。
- 想改日期或人數：在 GitHub 上打開 `config.json`，點鉛筆圖示編輯後 Commit。
- 官網如果改版，程式可能會看不懂畫面。這種情況下該飯店那次會略過（Actions 紀錄裡會顯示警告），不會誤發通知，但要找人更新程式。


## 防止自動停止
`.github/workflows/keepalive.yml` 每月 1 號、15 號自動更新一次 `keepalive.txt`。GitHub 公開倉庫 60 天沒更新就會停掉排程，有這個就不會停。
